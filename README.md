# Ubicaciones CD · Yagan Depot

App del centro de distribución para registrar ubicaciones, stock, reposiciones e inventarios a ciegas desde el celular.

- **App publicada:** https://bodega-yagan.github.io/ubicaciones-cd/
- **Pantalla:** `index.html` (este repositorio, publicado con GitHub Pages; aquí funciona la cámara en vivo).
- **Datos:** planilla de Google "Ubicaciones CD" + `Code.gs` en Apps Script (implementación: Ejecutar como *Yo*, acceso *Cualquier persona*).

Para actualizar la pantalla, reemplaza `index.html` y se publica sola en 1–2 minutos.
